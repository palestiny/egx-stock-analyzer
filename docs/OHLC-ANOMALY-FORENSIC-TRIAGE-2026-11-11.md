## 1. Scope and method

This note re-examines the 51 rows already classified by the committed read-only audit as `ohlc_inconsistency_review`. It reads the canonical CSV and the JSON artifact generated by the GitHub Actions daily-history audit. It does not retrieve new vendor prices, authenticate the source, or alter the archive.

For each flagged row, the diagnostic:
- classifies the geometry as `open_below_low` or `open_above_high`;
- groups rows by session date and the exact `retrieved_at` batch;
- identifies equity versus index instrument type;
- compares the flagged open with the immediately preceding dated close for the same symbol where such a row exists.

The prior-close comparison is a diagnostic clue only. It is not a reconciliation, and no candidate value is proposed.

## 3. Prior-close comparison

For 40 flagged rows with a preceding same-symbol observation in this archive, 22 opens match the prior row's close within numeric tolerance (10^{-8}). The other 18 do not. Eleven flagged rows have no preceding same-symbol row in the current 255-row archive and therefore cannot be tested this way.

This pattern is consistent with several competing possibilities, including a source/display convention, a capture or parsing issue, a genuine market-data representation, or a mismatch in session/field semantics. The present archive cannot distinguish among them. Equality with a prior close is not proof that the open was copied, nor proof that either value is correct.

## 4. Diagnostic interpretation — hypotheses, not findings

1. **Batch-level concentration:** the 19-row and 11-row cohorts on 4 and 5 November deserve first review because many instruments share one retrieval timestamp and the same geometry direction.
2. **Open-field focus:** every exception is an open outside the low/high envelope; all recorded closes remain inside the envelope. This narrows the field to investigate but does not establish which field is wrong.
3. **Cross-instrument scope:** equities and indices both appear, so the issue should not be presumed to be one equity's corporate action or one symbol's mapping.
4. **Provider independence:** alternate Investing.com locales/pages cannot independently validate the original Investing.com observation.

None of these hypotheses authorizes a field correction, forward fill, prior-close substitution, or removal.
